# Fan_DigitalTube_PWM 工程规划

> 华清 FS-STM32U5 套件（U575RIT6 核心板 + 底板 + FS_MP1A_Extend_v3.3 扩展板）
> 功能：按键控制风扇转速挡位，数码管显示挡位，另一路 PWM 持续输出渐变波形
> 版本 V1.0 规划稿 2026-09-28，实施前需用户确认

## 一、硬件资源核验结果（已对原理图原始文本逐项核对）

### 1.1 数码管在扩展板上，SPI4 用不了 —— 改走 SPI2（关键决策）

- 扩展板数码管 = FJ3461AH **4 位共阳** + 两片 M74HC595 菊花链：
  - U2（第一级）= 段选 DS_A~DS_DP + DS_HO，串 51R 限流
  - U6（第二级）= 位选 DS-G1~G4，串 100R
  - 数据流：SPI MOSI → U2（段）→ QH' → U6（位），**每刷新一次发 2 字节 [段码, 位选] 再给锁存沿**
- 扩展板 J1 丝印标 SPI4，但 **SPI4 的 AF 引脚全在 PE 口，U575RIT6 是 LQFP64 封装没有 PE 口** → SPI4 引不出来。这块板原配 MP1A，华清 U5 教程（第 6 章例程 10-1）的实际接法是**借用底板 J6 的 SPI2**：
  - 扩展板 J1.25 (SPI4_MOSI) → 底板 J6.25 (SPI2_MOSI = PB15)
  - 扩展板 J1.26 (SPI4_SCK)  → 底板 J6.26 (SPI2_SCK  = PB13)
  - 扩展板 J1.30 (SPI4_NSS/RCLK 锁存) → 底板 J6.30 (SPI2_NSS = PB12，软件锁存沿)
  - J1.28 MISO 不接（无回读需求）；J1.31/32=3V3、J1.33/34=GND 与底板 J6.31~34 对插
- ⚠️ 5 根杜邦线对插 + 共地，方向别插反；上电顺序无要求

### 1.2 风扇 / 第二路 PWM：底板 J6 直出

- 风扇 = **FAN 网络 = TIM3_CH1 = PC6**（底板 J6.7，驱动管在底板上，MCU 只给 PWM 信号不背功率）
- 第二路波形 = **TIM3_CH2 = PC7**（底板 J6.9，丝印 MOTOR）——同定时器双通道，时钟同源最干净
- 手册 17-3 实测：**占空比 70% 风扇才起转**（静摩擦死区），挡位映射必须避开 0<duty<70%

### 1.3 按键：底板 KEY1~3

KEY1=PC9 / KEY2=PC8 / KEY3=PC5（J6.10/11/12，低电平按下）。USER=PA12 备用。

### 1.4 现工程状态（Fan_DigitalTube_PWM）

- CubeMX 基础工程已建好：**时钟已是正确方案**（HSE=12MHz、PLLM=3/N=40→160MHz、EPOD=12M），ICACHE 已开
- keil2cubevscode 迁移产物已在（cmake/、build/、MDK-ARM/）
- 尚未配置任何外设（TIM/SPI/GPIO 均未配），git 未建

## 二、外设配置方案

| 外设 | 用途 | 关键参数 |
|---|---|---|
| TIM3 CH1 (PC6) | 风扇 PWM | 160MHz/64=**25kHz**（PSC=0, ARR=6400-1，无啸叫频段），CCR=duty%×64 |
| TIM3 CH2 (PC7) | 观测波形 PWM | 同 25kHz，占空比由软件渐变引擎驱动（三角波 0→100→0 循环） |
| SPI2 主模式 | 595 数码管 | **低速 ~1.25MHz**（MBR=128 分频；教程明确 SPI 过快 595 菊花链收错位），8bit MSB，PB12 软件锁存 |
| TIM6 | 5ms 时基 | 中断置标志，主循环做数码管扫描 + 按键消抖（ISR 不干活原则） |
| GPIO PB12 | 数码管锁存 | 推挽输出，默认低 |
| PC9/PC8/PC5 | 按键输入 | 内部上拉，**轮询采样不用 EXTI**（5ms tick 内消抖，比 EXTI+定时器消抖简单可靠；若想练 EXTI 后续可加） |

hal_conf.h 需手动开：HAL_TIM_MODULE_ENABLED / HAL_SPI_MODULE_ENABLED；
cmake/stm32cubemx/CMakeLists.txt 的 MX_Sources 需补 stm32u5xx_hal_tim.c / _tim_ex.c / hal_spi.c（脚本不会自动加，Sensor_Test 同款坑）。

## 三、功能逻辑

### 3.1 挡位定义与功率限制

| 挡位 | 风扇占空比 | 说明 |
|---|---|---|
| 0 | 0%（PWM 停止） | 完全关断 |
| 1~6 | 70% 起步，每挡 +5% → 70/75/80/85/90/95 | 全部落在起转死区之上 |
| 7 | 100% | 全速 |

- 软件限幅： duty 只允许 {0} ∪ [70,100]，Update_Fan() 入口拒绝区间外值（防呆，照手册 Update 模板 Stop→SET_COMPARE→清计数→Start）
- 功率承担方在底板驱动管，MCU 侧无功率风险；**PC7 观测通道只许接示波器/万用表，不要接电机本体**（想接电机得另评估堵转电流）
- 数码管位扫描占空比 1/4、段串 51R，无需额外处理

### 3.2 按键功能

- KEY1 = 挡位 +1（到顶回绕到 0）
- KEY2 = 挡位 -1（到 0 停）
- KEY3 = 风扇使能/禁用切换（禁用时风扇 PWM 停、数码管挡位闪烁提示或显示 "—"）

### 3.3 显示

4 位共阳数码管，显示格式 `F 0 x _`（F=Fan 标识 + 百位挡位提示 + 挡位数字，具体点亮方案实现时定），段码表共阳取反：{0x3F,0x06,...} 取 ~。
扫描方式：TIM6 5ms 置 flag → 主循环每次点亮一位，16ms/整帧无闪烁。

### 3.4 第二路渐变波形

TIM3_CH2 25kHz，占空比每 5ms ±1% 三角渐变（0→100→0 周期 1s），独立于风扇挡位持续运行。
示波器看 PC7：可见占空比缓变的方波包络；万用表直流档可见平均电压 0→3.3V 线性爬升。

## 四、软件架构（裸机，无 RTOS）

```
main.c            时钟/GPIO/TIM3/SPI2/TIM6 init（CubeMX 生成 + USER CODE 补丁）
fan.c/h           Update_Fan(duty) 限幅封装 + 挡位表
nixie.c/h         595 驱动（SPI2 发 2B + PB12 锁存沿）、帧缓冲、段码表
key.c/h           5ms 采样消抖状态机（连续4次同电平=有效）
渐变引擎          主循环 5ms tick 里 duty 三角更新 + __HAL_TIM_SET_COMPARE
HAL_TIM_PeriodElapsedCallback   TIM6 → g_tick_flag=1（只置标志）
```

注释规范：WT-WI-PE-200 B1（六字段文件头 + 函数五要素 + U 后缀魔法数字宏化）。
串口调试输出（可选）：本项目不带 USART，靠数码管+示波器即可观测；要加 printf 再说。

## 六、已规避的坑（来自技能库，施工时对照）

1. HSE=12M 已在 .ioc 配对 ✓（但 hal_conf.h 的 HSE_VALUE 生成后仍要核对 12000000UL）
2. -mcpu 必须 cortex-m33（阶段 0 编译时核对 ninja 命令行）
3. SPI 过快 595 错位 → 初始就配 1.25MHz
4. ISR 只置标志，扫描/消抖全在主循环
5. LQFP64 无 PE 口 → 不碰 SPI4/不碰 PE 系列引脚
6. CubeMX 重新生成会打回时钟参数 → 本工程 .ioc 已存对，重生成后 diff main.c 时钟函数
